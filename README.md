# BugilCoin
북일고등학교의 여러가지 지표들을 활용하여 활성도에 따라서 가격이 변동하는 **북일코인**

# 사용 지표
- 1차지표: 북일고등학교 디시인사이드 갤러리, 리로스쿨의 반응성.
    - 단 해당 지표는 인위적 조작 가능성이 존재하여 변동 로직에 있어서 한계선을 주고 1차 상한선을 지정함.
- 2차지표: AI 기반 랜덤화 에이전트들의 인위적 매수/매도 움직임.
    - 실제 시장과 같이 5~10개의 랜덤 에이전트들이 특정 알고리즘을 기반으로 매수, 매도를 실시함. 
- 3차지표: 랜덤 지수
    - 어느 정도 1차, 2차 지표 사이의 영향력 크기대조를 위하여 랜덤값을 사용함.
